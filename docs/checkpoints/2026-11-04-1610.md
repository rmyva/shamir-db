## Decisions

- Флейк wasm-host на macOS: не поднимать wall-clock, а завершать цикл по числу наблюдений (5 000) или остановке писателя на 30 с (CLAUDE.md запрещает маскировать нехватку CPU таймаутом); fjall `Locked` в e2e-харнессе лечится повтором запуска, как в соседних харнессах.
- Rust-клиент: токен только через собственный hyper-клиент (tungstenite логирует Authorization); `handshake/bearer.rs` перенесён в `handshake/token/` ради лимита 7 записей; логин по паролю без пина Ed25519, класс безопасности только из endpoint.
- TS Node: режим выбирается явной опцией `transport`, умолчание не меняется; экспортер в `auth_message` только для режима 0x01; узкая перегрузка браузерного `connect` отменена (ломала типизацию существующего теста).
- napi: сгенерированные файлы берутся из артефакта CI (локальные сборки запрещены); `login` реэкспортирован из корня крейта, чтобы не быть dead code в `cfg(test)`; e2e делит одну админскую сессию (лимит `MAX_SESSIONS_PER_USER = 16`).
- Матрица: ячейка «да» только вместе с e2e, который её доказывает.
