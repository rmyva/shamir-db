## Decisions

- Двухуровневая компиляция Winch→Cranelift принята пользователем; Pulley — не быстрый уровень (20–80× медленнее), только запасной вариант; wasmi остаётся запасным, не берём без нужды.
- Хеш содержимого wasm: фиксированный массив из 2–3 быстрых движков вместо SHA-256; без секретного seed и без обязательного побайтового сравнения (решение пользователя: подбор коллизии возможен только актором внутри периметра); частота проверок — создание, первая загрузка в память, выгрузка, репликация, никогда на вызове; в KNOWN_LIMITATIONS одна строка про общий кэш при недоверенных авторах.
- Тип компилятора на исполнение не влияет (важен контракт ABI, версия ABI в custom-секции модуля), метка происхождения только информационная.
- Флейки чинятся по механизму из кода; если сбой не воспроизводится — ставим точные замеры и ждём срабатывания (так для #1802), таймауты не поднимаем.
- Rush-исполнители каждый раз возвращали FAIL-ревью с реальными дефектами: приёмка всегда построчная, исправления делаю сам.
