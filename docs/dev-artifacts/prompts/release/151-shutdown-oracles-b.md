## Items

1. **A typed flusher outcome instead of a string re-derivation (task #2008 item 3).** `FjallAuditAppender::join_flusher` returns `Result<(), String>` for two different shapes: (a) the flusher task joined and reported that its INNER blocking job failed (a panic after the task took the buffer; the blocking work has ended, the appender is latched fail-closed), (b) the OUTER `JoinError` (the task itself panicked or was cancelled: nothing proves its blocking work stopped). `AuditShutdownOutcome::flusher_join_error: Option<String>` collapses them the same way, and `audit_teardown.rs` re-derives which shape it got by comparing the message with the appender's latched cause through `latched_cause`, only to decide whether the final close may still be submitted. Required: a typed result that names the two shapes (an enum; the names are yours), carried by `join_flusher` and by the outcome, with the teardown decision (`flusher_stopped`, and whether a close is skipped) driven by the variant, not by a string comparison with the latch. The existing report texts and prefixes (`ERR_FLUSHER_JOIN`, `ERR_FLUSH`, `ERR_FINAL_CLOSE_SKIPPED`) and the once-per-failure suppression of the same message under another prefix must keep their observable behaviour (existing tests pin them: read them and say which). Find every consumer with a workspace grep (`join_flusher`, `flusher_join_error`, `AuditShutdownOutcome`, tests included) and update it. The new type is its own file (one primary item per file) and is re-exported through the existing `pub use shutdown::{...}` line without adding lines to `audit_appender.rs` (or through a different re-export that keeps that file at or below 999 lines).

   Then add the missing oracle: an ORDINARY latched flush failure (the `arm_fail_next_flush` fault injection, NOT a panic) combined with a SKIPPED final close (for example a scheduler tick that never returns, as in `run_scheduler_tick_never_returns`) must reach the shutdown report exactly once, under the flush prefix, and the final close must not be submitted (`final_close_attempts() == 0`).
