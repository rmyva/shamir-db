## Items (this step)

### 1. A lock/context leak on the commit path before the commit driver owns cleanup (P1 candidate)
`crates/server/shamir-server/src/engine/db_handler/repo_admin/tx_handlers.rs` (around lines 536-543) takes the transaction context out of the registry; `crates/engine/shamir-db/src/shamir_db/execute/core/db_tx.rs` (around lines 387-425) resolves the repository by NAME, then awaits authorization and releases the context inline on a denial. Claimed defects: (a) a name lookup failure (repository renamed, commit under the old name) returns BEFORE any release, so locks and the context leak until the registry reaps them; (b) a disconnect or cancellation during the denial release can drop the context without its release. Fix: a cleanup owner (an RAII guard) bound to the ALREADY RESOLVED repository that releases exactly once on every exit (denial, lookup failure, cancellation, drop) until the commit pipeline takes ownership; a normal commit must not release twice. Tests: rename the repository between begin and commit (the commit fails typed and the locks are released), a denial path, a drop of the commit future before the pipeline starts, and a control that a successful commit still releases exactly once. Use the existing test seams; add a seam only where nothing deterministic exists, and say so.

### 2. `CancelTx` under handle reuse: state and identity must be read coherently
`crates/server/shamir-server/src/.../tx_cancel.rs` (search for it; around lines 33-59): the initial `Committing` state and the activity row come from separate reads, and the busy re-read and the removal accept an identity-free `Committing` result, so a reused handle can be cancelled or removed for a different transaction. Fix: capture state and identity coherently under the registry's open-entry guard and carry the identity through `Open` -> `Committing`; every later re-read and removal compares the identity. Tests: handle reuse (a second transaction under the same handle is never cancelled or removed by a stale cancel), both outcomes of a cancel racing a commit.
