## Goal and why
The design rests on facts about serde that nobody has verified on this tree: that every derived identifier accepts an integer equal to the declaration index, that the serializer side can count fields the same way, and that a pinned, committed dictionary can be rebuilt from the code and compared by a test. A wrong assumption found after step 2 costs a protocol version. This step establishes the facts, builds the pinning machinery and produces the audit that tells step 2 exactly which types can be indexed.
